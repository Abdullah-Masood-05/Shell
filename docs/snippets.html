Snippets


A snippet is a ready-made .nss file that adds a menu or a few items to the context menu, for example a 7-Zip menu or a way to copy a file's path. You save the file next to your configuration and add one line to shell.nss that loads it. You don't have to write any of it yourself.

Snippets by RubicBG

The largest collection is Nilesoft Shell Snippets by RubicBG. It is not part of Nilesoft Shell Pro and is not maintained by this project; all credit for the snippets goes to RubicBG. The files are sorted into folders by topic:

ex1.systemWindows features: a replacement Open with menu, a larger Send to menu, keyboard shortcuts, saving a copied image from the clipboard, and shortening long file names.
ex2.user.cloud.shareOneDrive, Dropbox, Google Drive and odrive menus, sharing through Tailscale or Viber, and uploading files to online file and text sharing services.
ex3.archiverMenus for 7-Zip, NanaZip, WinRAR and Universal Extractor, plus compressing and extracting with the tools built into Windows.
ex3.multifunctionFile tools: copy path in different forms, copy file hashes, copy a list of names, drive tools, security and permission tools, links and shortcuts, and renaming.
ex4.terminalA terminal menu for Command Prompt, PowerShell and Windows Terminal, with a way to open them as administrator.
ex5.gotoGo to menus for common folders, registry keys, Run commands and Windows settings pages.
ext.managers, ext.desktop, ext.nilesoft, ext.othersPower options, Everything search, Windows version details, menus to manage Shell itself, and items for the desktop, the Recycle Bin, the address bar and the navigation pane.
dev.develop, dev.helpersHelpers for people who write their own menus, such as lists of icons and paths.

Many snippets have a .md page next to them with a description and a screenshot. Start from the readme, which links to them by group.

The moudey/nilesoft-shell-snippets repository is an older copy of the same collection. Use RubicBG's repository for the current files.

Info: The collection is written for the newest upstream test builds of Nilesoft Shell. A few snippets use functions that Nilesoft Shell Pro doesn't have yet: str.fmt, app.set, app.exists, app.delete, path.file.save_box, input() with more than three arguments, and appx(id, 'path'). Those snippets won't load here; most of the others load normally.
Warning: Read a snippet before you use it. Some of them run commands as administrator, change system settings, or send your files to online services. Open the .nss file on GitHub and look at what each item runs. If you are unsure, don't add it.

Use a snippet

These steps use your personal configuration in %APPDATA%\Nilesoft\Shell, which you can change without administrator rights. If you don't have one yet, press Use per-user config on Home in the Nilesoft Shell Pro app.

  1. Open the snippet's .nss file on GitHub and use Download raw file (the download button above the file).
  2. Save it in the imports folder of your configuration: %APPDATA%\Nilesoft\Shell\imports. Keep the file's own name, for example app.SevenZip.nss.
  3. Open shell.nss (in the app: Config Editor) and add this line at the end, with the name of your file: 
    import 'imports/app.SevenZip.nss'
  4. Save. Shell picks up the change on the next right-click.

The path in the import line is relative to shell.nss, so imports/ means the imports folder next to it. Write import and the quoted path only, without settings or theme in front; see Import tag for the details.

If you use the shared configuration in the install folder instead (C:\Program Files\Nilesoft Shell), the steps are the same with that folder's imports folder and shell.nss, but saving there needs administrator rights.

Without a separate file. You can also copy the text of the snippet and paste it at the end of shell.nss in the Config Editor. The editor checks it before saving and lists any error in Problems.

To remove a snippet, delete its import line (or the pasted text) and save. Your own files in imports are left alone when Nilesoft Shell Pro updates.

If the menu disappears after adding a snippet, the snippet most likely uses one of the functions listed above. Open the Config Editor, look at Problems, and remove the line again. Every save in the app takes a snapshot first, so you can also go back from Backups.


Write your own

To change a snippet or make your own menus, start with Get Started, then New items and Modify items. The Examples show a few complete menus.
