Nilesoft Shell Pro

Warning: Read this before installing.
  1. Uninstall the original Nilesoft Shell first. The two don't replace each other, and with both installed the menu can disappear or show up twice. Use Settings → Apps → Installed apps; for an old portable copy, run shell -unregister -restart from its folder, then delete the folder. How to uninstall it
  2. Windows may block it, because it isn't code-signed. If the installer or the app won't open, right-click the download, choose Properties and tick Unblock. If a blue box says Windows protected your PC, choose More info, then Run anyway. If Smart App Control blocks it, turn Smart App Control off in Windows Security → App & browser control.
  3. If Microsoft Defender removes a Shell file, restore it from Windows Security → Virus & threat protection → Protection history, and add the Shell folder as an exclusion so it doesn't happen again. Step-by-step guide

A better right-click menu for Windows 11 and Windows 10. Add the commands you use, hide the ones you don't, and change how the menu looks. The settings app does it for you, so you never have to edit code.

Get going in four steps
  1. Download and run the installer. Windows asks for permission once. If a blue box says Windows protected your PC, choose More info, then Run anyway. Why Windows shows this
  2. Right-click the desktop or any file. The new menu is already on. On Windows 11 it replaces the short menu, so you don't need Show more options any more.
  3. Open Nilesoft Shell Pro from the Start menu. The first time, a short setup makes your own copy of the settings and lets you pick a look.
  4. Make the menu yours. Change colours and fonts, add your own items, or turn on ready-made extras. Each change is checked before it is saved, and a backup is kept, so you can always go back.

Prefer to write the configuration yourself?

The menu is described in a plain text file, shell.nss. The app writes it for you, but you can also edit it by hand. These pages are for that:

  • Get started with code: your first menu item.
  • Configuration: settings, themes, and adding or changing items.
  • Expressions and Functions: the language reference.
  • Examples and Snippet collections: menus you can copy.
  • Command line: the options of shell.exe.
Who makes it

Nilesoft Shell was created by Moudey and Nilesoft. Nilesoft Shell Pro is a fork of it that adds the settings app, setup for your account only, and many fixes. The menu language is the same. About this fork
