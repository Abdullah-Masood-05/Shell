COMMAND
command.copy, command.copy_to_clipboard

copy to parameter clipboard.

Syntax

command.copy('string copy to clipboard')
command.sleep(milliseconds)

Suspends the execution of the current thread until the time-out interval elapses.

Syntax

command.sleep(1000)
command.random

Suspends the execution of the current thread until the time-out interval elapses.

Syntax

command.random(min value, max value)
command.navigate

Opens a folder in the same explorer window. In an Open or Save As box it opens the folder in that box, and the file name you typed stays as it is.

Syntax

command.navigate(path)
item(title='Desktop' where=wnd.is_dialog cmd=command.navigate(user.desktop))
command.refresh

Refreshes the window the menu was opened on.

Syntax

command.refresh                                // refresh, as F5 does
command.refresh(1)                             // send the refresh straight to the window the menu opened on
command.refresh(2)                             // refresh, and rebuild the Windows icon cache (ie4uinit.exe -show), for icons that show wrong
command.empty_recycle_bin

Empties the Recycle Bin on every drive. It does not ask first, so put a msg() question in front of it. Windows shows its progress window while it works. If the Recycle Bin is already empty, nothing happens. If one drive can't be emptied, the other drives still are, and the reason is written to shell.log. If you press Cancel in Windows' progress window, it stops and the files that are left stay in the Recycle Bin.

Syntax

command.empty_recycle_bin
item(title='Empty Recycle Bin' cmd=if(msg('Empty the Recycle Bin?', app.name, msg.yesno | msg.warning) == msg.idyes, command.empty_recycle_bin))
