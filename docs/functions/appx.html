APPX


appx or appx.path

Returns the path of Package.

Syntax

appx(packageName)
appx.path(packageName)

Parameters

packageName
can be passed in full name or part of name.

Example

appx.path("WindowsTerminal")
// result:
// C:\Program Files\WindowsApps\Microsoft.WindowsTerminal_1.11.3471.0_x64__8wekyb3d8bbwe
appx.name

Syntax

appx.name(packageName)

Parameters

packageName
can be passed in full name or part of name.

Example

appx.name("WindowsTerminal")
// result:
// Windows Terminal

appx(packageName, property)

Returns one value of the Package, named by the second argument. Without it, appx(packageName) is the path, as before. Returns nothing when the package or the value is not found.

Syntax

appx(packageName, property)

Parameters

packageName
can be passed in full name or part of name.
property
one of these (upper or lower case):
  • 'path', 'name', 'id', 'family', 'version', 'shell': the same as the functions above.
  • 'executable': the full path of the app's program file.
  • 'entrypoint': the app's entry point, as written in its manifest.
  • 'logo': the package logo (the one the Store shows).
  • 'square150' (or 'square150x150logo'): the app's medium tile image.
  • 'square44' (or 'square44x44logo'): the app's small icon, the one in the Start menu's list.

The values other than path, name, id, family, version and shell come from the package's AppxManifest.xml, read once per package.

Example

appx("WindowsTerminal", "executable")
// result:
// C:\Program Files\WindowsApps\Microsoft.WindowsTerminal_1.24.12741.0_x64__8wekyb3d8bbwe\WindowsTerminal.exe
appx.executable

Returns the full path of the app's program file. The same as appx(packageName, 'executable').

Syntax

appx.executable(packageName)

Parameters

packageName
can be passed in full name or part of name.

Example

item(title='Terminal' image=appx.executable("WindowsTerminal") cmd=appx.shell("WindowsTerminal"))
appx.entrypoint

Returns the app's entry point, as written in its manifest.

Syntax

appx.entrypoint(packageName)

Example

appx.entrypoint("WindowsTerminal")
// result:
// Windows.FullTrustApplication
appx.logo, appx.square150, appx.square44

Return the path of the package logo, the medium tile image and the small icon.

A manifest names an image as Images\StoreLogo.png, while the package installs it as Images\StoreLogo.scale-200.png, Images\StoreLogo.targetsize-48.png and so on. These functions return the installed file that best fits the screen scale (high contrast versions last). When no such file is there, they return the image's folder.

Syntax

appx.logo(packageName)
appx.square150(packageName)
appx.square44(packageName)

Example

appx.square44("WindowsTerminal")
// result at 100% scale:
// C:\Program Files\WindowsApps\Microsoft.WindowsTerminal_1.24.12741.0_x64__8wekyb3d8bbwe\Images\Square44x44Logo.scale-100.png
