app.set, app.get, app.exists, app.remove (app.delete)

Remember a piece of text between menus, even after a restart. Each value has a name of your choice.

  • app.set(name, value) stores the value as text. Returns true when it was saved.
  • app.get(name) returns the stored text, or nothing when there is none.
  • app.exists(name) returns true when a value with that name is stored.
  • app.remove(name) or app.delete(name) forgets the value. Returns true when one was removed.

The name can't be empty. Values are kept for the current Windows user, in the registry under HKEY_CURRENT_USER\Software\Nilesoft\Shell\Variables. Uninstalling Shell leaves them there.

Use app.set and app.remove in cmd, so they run when the item is clicked. In where, title or another property they would run every time the menu opens. app.get and app.exists are fine anywhere.

Syntax

item(title='Remember this folder' cmd=app.set('fav', sel.dir))
item(title='Go to ' + app.get('fav') where=app.exists('fav') cmd=app.get('fav'))
item(title='Forget the folder' where=app.exists('fav') cmd=app.remove('fav'))
