Settings app


Nilesoft Shell Settings (settings.exe, next to shell.exe in the program folder) is a desktop app for checking an installation and editing the configuration without opening shell.nss by hand. It is part of this fork and is still being built; the pages below are marked where they are not finished yet.

Info: The app runs as the current user and needs no administrator rights. It works on the per-user configuration in %APPDATA%\Nilesoft\Shell and the per-user registration under HKEY_CURRENT_USER. The only action that asks for administrator rights is machine-wide registration in Preferences, which is marked with the UAC shield.
First run

On first start the app offers three steps:

  1. create the per-user configuration (shell -config:init);
  2. register Shell for the current user (shell -register -user);
  3. restart Explorer. Choosing a look here arrives with the Appearance page.
Home
  • Health: whether Shell is registered (none, user, machine or both), the state of the Windows 11 classic-menu redirect, the DLL in use and the version.
  • Active configuration: which shell.nss Explorer loads and where it was found, with an action to switch to a per-user copy.
  • Diagnostics: recent errors from shell.log. Each one opens the file at that line in the Config Editor.
  • Quick actions: register or unregister for the current user, restart Explorer, open the configuration folder, and run first-time setup again.

The app reads all of this through shell -status, so it shows the same state the command line reports.

Appearance
Note: This page is in development.

Theme, dark mode, density, background colour, opacity and effect, font, corner radius, border and shadow, with a live preview of the menu on your wallpaper in light and dark. Only the keys you change are written, to an app-owned imports\settings-app.nss imported last by shell.nss, so your own theme settings stay as you wrote them.

Config Editor
  • A tree of shell.nss and every file it imports. Imports that cannot be found are marked.
  • A highlighted read view with line numbers and problem markers, and an edit view.
  • While you type, the edit is checked with shell -config:check on a temporary copy, so the menu you are using is not affected. Problems link to their line.
  • Saving keeps the file's encoding, byte order mark and line endings. A file with errors is not saved unless you confirm, because one parse error turns the whole Shell menu off.
  • Files changed on disk by another editor are reloaded, or flagged if you have unsaved edits.
  • The shared configuration in the program folder is read-only here; the editor offers to create a per-user copy.
Backups

Every save first takes a snapshot of the configuration in %APPDATA%\Nilesoft\Shell\backups. The Backups page lists them with the time, the reason and the files changed. You can:

  • compare a snapshot with the current files, line by line;
  • restore a snapshot;
  • pin a snapshot so it is never removed when old snapshots are cleaned up;
  • create a snapshot by hand, delete one, or open the folder.
Preferences

The app's own theme, registration for all users (needs administrator rights), and version and licence information.

Applying changes

There is no restart step for configuration changes: Shell reloads the configuration when a file it loaded changes. Registration changes still need Explorer to restart, which the app does for the current session only.
